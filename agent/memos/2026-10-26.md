## 3. Decide

At most 3 changes. Each is a proposal only. Nothing is applied this session.

1. **Add a near-duplicate-story guard in selection.**
   - *Evidence:* the Ernesto and polarbeargrowth posts (10-22, 2 hours apart) told the same story, and the second got 6v versus 22v for the first. With reads at 130-200 a day, the same viral story will now reach us via several authors.
   - *Change:* in `select/rules.py`, skip a candidate whose lead text matches a post published within 7 days. Use a cheap check such as token overlap on the first 120 characters, or reuse the existing posted-history comparison if there is one. This is a code change, so it's a separate small PR with a golden test. Run `pytest` first.
   - *Predicted effect:* no same-story repeats, and the second slot goes to a different story. Median views rise slightly because the repeat gets about 6v.
   - *Revert condition:* if more than 2 candidates per week are rejected as false positives, loosen the threshold.

2. **Check the `fabricated_number` false positives on single digits.**
   - *Evidence:* the blocks on "1", "3" and "10" for use-addy, witscode and wepushers.
   - *Change:* read the three source texts and the drafts. If the digits are list markers or spelled-out numbers, extend the exemption in `commentary/safety.py` and add a golden test. If the drafts really did invent the digits, change nothing.
   - *Predicted effect:* a few more drafts get through, only if the check finds false positives. If it doesn't, no change.
   - *Revert condition:* any fabricated number reaches a published post.

3. **Hold image_card and author_bait until day 21, then apply the fixed rule.**
   - *Evidence:* both arms are below the sample floor. image_card hits day 21 on 10-30, author_bait on 10-29.
   - *Change:* none this week. If card still trails text by 30% or more at day 21, the memo next week proposes `image_card.enabled: false`. If author_bait's question arm has under 5 posts, the verdict is "no difference" and I'd propose extending it with a higher question share.
   - *Predicted effect:* a clean read next week.
   - *Revert condition:* not applicable.

**Deliberately not changing:** the topic mix, voice, thresholds, source mix and caps. The follower rise of +4 is a possible effect of the new List source and higher volume, and I don't want to disturb it before I can tell which factor matters. Also, `scoping.source_timeline: both` raises read costs, and reads are at 1471 of 5500 this month, so the budget is fine.
